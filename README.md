# Yanchhuong Suon — Professional Profile

A responsive personal profile site built as a static site (HTML, CSS, and vanilla JS) with no build step, ready for Vercel.

## Structure

```
index.html        page markup
css/styles.css    styles (desktop → tablet → mobile breakpoints at 1024 / 768 / 480px)
js/main.js        SITE config, project filter, mobile menu, contact form
jarvis-widget.js  "Ask AX Assistant" chat button (talks to the n8n public chat workflow; only works on allowed domains)
contact-form.js   sends the contact form to Telegram via n8n
assets/           images
vercel.json       Vercel headers & clean URLs
```

## Edit your details

Open `js/main.js` and fill in the `SITE` block at the top:

```js
const SITE = {
  email: 'hello@yourdomain.com',
  cvUrl: '/assets/Yanchhuong-Suon-CV.pdf',
  linkedinUrl: 'https://www.linkedin.com/in/your-handle'
};
```

The **Download CV** buttons and the **LinkedIn** icon stay hidden until `cvUrl` and `linkedinUrl` are set.

What I do, Technology stack, and Projects & initiatives are written directly in `index.html` (not generated by JavaScript), so search engines, link previews, and the AX Assistant chatbot's source text all see them. To change a project, edit its `<article class="project" data-cat="…">` card; `data-cat` must match one of the filter buttons (`platform`, `fintech`, `ai`).

## Run locally

```bash
npx serve .
# or
python -m http.server 8000
```

## Deploy to Vercel

1. Go to https://vercel.com/new and import this GitHub repository.
2. Framework preset: **Other**. Leave the build command and output directory empty.
3. Deploy. Every push to `main` redeploys automatically.
