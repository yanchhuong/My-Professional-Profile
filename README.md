# Yanchhuong Suon — Professional Profile

A responsive personal profile site built as a static site (HTML, CSS, and vanilla JS) with no build step, ready for Vercel.

## Structure

```
index.html        page markup
css/styles.css    styles (desktop → tablet → mobile breakpoints at 1024 / 768 / 480px)
js/main.js        SITE config, project filter, mobile menu, contact form
jarvis-widget.js  "Ask AX" chat button (talks to the n8n public chat workflow; only works on allowed domains)
contact-form.js   sends the contact form to Telegram via n8n
assets/           images
vercel.json       Vercel headers & clean URLs
```

## Edit your details

Open `js/main.js` and fill in the `SITE` block at the top:

```js
const SITE = {
  email: 'hello@yourdomain.com',
  cvUrl: '/assets/Yanchhuong-Suon-CV.pdf',
  linkedinUrl: 'https://www.linkedin.com/in/your-handle'
};
```

The **Download CV** buttons and the **LinkedIn** icon stay hidden until `cvUrl` and `linkedinUrl` are set.

What I do, Technology stack, and Projects & initiatives are written directly in `index.html` (not generated by JavaScript), so search engines, link previews, and the AX chatbot's source text all see them. To change a project, edit its `<article class="project" data-cat="…">` card; `data-cat` must match one of the filter buttons (`platform`, `fintech`, `ai`).

## Languages (Khmer by default)

The site opens in Khmer; the **EN / ខ្មែរ** button in the header switches language, and the visitor's choice is remembered.

Every piece of text is written twice in `index.html`, and CSS shows only the language set on `<html lang>`:

```html
<h3><span lang="km">វិស្វកម្មកម្មវិធី</span><span lang="en">Software engineering</span></h3>
```

Attributes hold the Khmer text, with the English in a `data-en-*` attribute (`placeholder` + `data-en-placeholder`, `aria-label` + `data-en-aria-label`, `alt` + `data-en-alt`). When you add or change text, update both languages. Text that is the same in both (product names, tech tags) needs no spans. The chat widget and contact form keep their own Khmer and English copy in `jarvis-widget.js` and `contact-form.js`.

## Run locally

```bash
npx serve .
# or
python -m http.server 8000
```

## Deploy to Vercel

1. Go to https://vercel.com/new and import this GitHub repository.
2. Framework preset: **Other**. Leave the build command and output directory empty.
3. Deploy. Every push to `main` redeploys automatically.
